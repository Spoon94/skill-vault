# hao Skill 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Roles: quill designs and reviews; verse (w2:p9) implements; quill verifies each task before the next starts.

**Goal:** Rename the `herdr-agent-ops` skill to `hao` and reposition it as a tiered multi-agent collaboration skill: a 27-role catalog tagged top/mid/low, roles carried in pane labels, briefs sized by tier, and a documented plan→decompose→implement→review workflow.

**Architecture:** Zero-registry as before: the pane label `hao-<name>-<role>` is the only persistent carrier of both the agent name and its role; `restore` recovers both. Roles live in a data table (`references/roles.md`); the tier of a role selects the brief in `hao ask` (compact for `top`; the full brief for `mid` / `low` / unroled targets, plus a default output cap by tier). Nothing else about the ledger, wait loops, sentinel matcher or the other commands changes.

**Tech Stack:** Python 3.9+ standard library only; herdr ≥ 0.9.5; Markdown data files; `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-26-hao-skill-design.md` (v3, approved).

## Global Constraints

- Skill directory is `hao/`, tests in `tests/hao/`; CLI is still `hao`. No compatibility shim for the old name.
- `hao` stays inside the skill directory; never installed or copied elsewhere.
- Do NOT modify the sentinel matcher (`_token_matches`, `_join_wrapped_sentinels`, `_confirm_sentinel`, `SENTINEL_RE`, `_PREFIX_LINE_RE`, `_HEX_CONT_RE`) or the hit/confirmation logic.
- Role names match `^[a-z][a-z-]{6,19}$` (7–20 chars) so they can never collide with agent names (`^[a-z]{4,6}$`). Tiers are exactly `top`, `mid`, `low`.
- Label role segment may be up to 20 chars: `HAO_LABEL_RE = re.compile(r"^hao-([a-z]{4,6})(?:-([a-z0-9][a-z0-9-]{0,19}))?$")` (herdr accepts long labels — verified live up to 51 chars).
- Naming and role are decoupled: `hao suggest` picks names by task keywords exactly as today; `--scope` is removed from `suggest` and `name`, replaced by `--role` on `name` only.
- Default output caps by tier: `top` 15 lines, `mid` 40, `low` unlimited; `--max-lines N` overrides, `0` means unlimited, negative → exit 2.
- Every command keeps its current exit-code and JSON contracts (one JSON object on stdout with `--json`; errors as one stderr line with a specific reason).
- Tests must pass in three modes: normal, herdr unreachable (PATH shim `exit 1`), and the integration smoke. Every test module that loads `scripts/hao` installs the offline guard; every public flag and optional positional must appear in `hao/README.md` (existing guard tests enforce both).
- Process for the implementer: no real agents are prompted or sent keys in tests (use stubs and `HAO_STATE_DIR` temp dirs); never `pkill -f`/`killall`; do not touch `~/Code/cli-zoo*` or `~/.local/state/hao`.

2. **Stale `--scope` / `scope` references** in tests, SKILL.md, protocol.md, restore.md and JSON keys — the doc guard only checks README, so grep the rest by hand.

ROLE_RE = re.compile(r"^[a-z][a-z-]{6,19}$")
TIERS = ("top", "mid", "low")
_ROLE_ROW = re.compile(
    r"^\|\s*`([a-z][a-z-]*)`\s*\|\s*(top|mid|low)\s*\|\s*([^|]+?)\s*\|\s*([^|]+?)\s*\|\s*$")


def _load_roles(path=None):
    if path is None:
        try:
            here = os.path.dirname(os.path.abspath(__file__))
        except NameError:
            here = os.getcwd()
        for cand in (os.path.join(here, "..", "references", "roles.md"),
                     os.path.join(os.getcwd(), "references", "roles.md")):
            if os.path.exists(cand):
                path = cand
                break
    roles = {}
    with open(path, encoding="utf-8") as f:
        for line in f:
            m = _ROLE_ROW.match(line)
            if m:
                roles[m.group(1)] = {"tier": m.group(2), "group": m.group(3), "duty": m.group(4)}
    for role in roles:
        if not ROLE_RE.match(role):
            raise ValueError(f"invalid role name: {role!r}")
    return roles


ROLES = _load_roles()


def tier_of(role):
    meta = ROLES.get(role or "")
    return meta["tier"] if meta else None
